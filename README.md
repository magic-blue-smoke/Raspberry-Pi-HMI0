# Raspberry-Pi-HMI0
Raspberry Pi CM0 4" HMI Panel for interactive display applications and DIY/hobbyist projects

# Preliminary specs/ideas
- Raspberry Pi CM0, WiFi
- 4" LCD display with CTP
- HDMI connector
- CSI camera interface
- USB-A x2
- SD-card
- Audio (headphone jack or speaker)
- USB type-C for power
- User buttons
- User LEDs
- Extension header
- qwiic connector
- RTC(?)
- Audio-in(?)
- Environment sensors(?)
- acc/gyro(?)
